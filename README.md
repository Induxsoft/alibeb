# Alibeb.
El paquete Alibeb de V12 es el módulo especializado en la administración integral de alimentos y bebidas dentro del sistema Induxsoft, permitiendo gestionar catálogos, recetas, líneas de productos y aplicaciones como la comandera web. Su función principal es centralizar la información de insumos, costos, precios y procesos de producción para restaurantes, bares y negocios de hospitalidad.
